# Smart Meter Model

The **Smart Meter Model** is the fundamental unit of simulation in the GridTokenX ecosystem. It emulates the behavior of industrial-grade meters, including energy profiling, cryptographic security, and grid-edge intelligence.

## 📐 Meter Implementation

The `SmartMeter` class (located in `src/smart_meter_simulator/core/meter.py`) handles all meter-level operations:

1.  **Energy Profiling**: Calculates time-of-day based consumption and solar generation.
2.  **Cryptographic Signing**: Uses **Ed25519** to sign every reading, ensuring data integrity from the source.
3.  **Accuracy Modeling**: Simulates measurement noise based on **ANSI C12.20** accuracy classes (from Class 0.2 to Class 2.0).
4.  **Grid Response**: Implements **Frequency-Watt Droop Control** and responds to VPP dispatch commands.

## 📊 Accuracy and Channels

Each meter type is assigned an accuracy class and a set of active measurement channels:

| Meter Type | Accuracy Class | Active Channels |
| :--- | :--- | :--- |
| **Residential (RES)** | Class 2.0 | $P, E$ |
| **Commercial (COM)** | Class 1.0 | $P, Q, E, V, I$ |
| **Solar Prosumer (SOL)** | Class 1.0 | $P_{gen}, P_{cons}, E$ |
| **Substation (SUB)** | Class 0.2 | $P, Q, E, V, I, f, \phi$ |

## 🔋 Integrated Battery & EV Logic

Meters can be configured with local storage (batteries) or EV chargers. The simulation includes dynamic state-of-charge (SoC) management and **Vehicle-to-Grid (V2G)** discharge capabilities based on market signals.

### Logic Flow

1.  **Calculate Base Net Generation**: $P_{net} = P_{solar} - P_{load}$
2.  **Apply Grid Stress**: $P_{load} = P_{load} \times \text{Multiplier}$
3.  **V2G/VPP Response**: Adjust battery SoC if dispatch setpoint is received.
4.  **Frequency Droop**: If frequency falls $> 0.05$ Hz, decrease load or increase generation within specified limits.

## 🔐 Security: Ed25519 Signing

Every `EnergyReading` generated by the meter is signed using its unique private key.

```python
# Payload Format: {energy_amount_kwh}|{iso_timestamp}
payload = f"{reading.energy_generated:.6f}|{reading.timestamp.isoformat()}"
reading.meter_signature = self.key_manager.sign_data(payload)
```

The **Oracle Bridge** and **API Gateway** verify this signature against the meter's public key (retrieved from the spatial registry) before persisting data.
