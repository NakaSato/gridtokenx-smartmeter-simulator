# EnergyReading Model

The `EnergyReading` is the fundamental data structure representing a single smart meter measurement interval. It carries energy metrics, electrical parameters, DER state, and cryptographic signature.

## Summary

Every tick of the simulation produces an `EnergyReading` for each meter. The model is defined in both Python (`models/reading.py`) and Rust (`src/rust_sim/src/lib.rs`) with field-level compatibility.

## Complete Field List

### Identity

| Field | Type | Unit | Description |
|-------|------|------|-------------|
| `meter_id` | str | — | Unique meter identifier (e.g., "AMI_METER_001") |
| `timestamp` | str | ISO 8601 | Reading timestamp (UTC) |

### Energy Metrics

| Field | Type | Unit | Description |
|-------|------|------|-------------|
| `energy_generated_kwh` | float | kWh | Energy generated in the interval |
| `energy_consumed_kwh` | float | kWh | Energy consumed in the interval |
| `surplus_energy` | float | kWh | Net export (gen - cons, if positive) |
| `deficit_energy` | float | kWh | Net import (cons - gen, if positive) |

### Electrical Parameters

| Field | Type | Unit | Description |
|-------|------|------|-------------|
| `voltage_v` | float | V | Line voltage (nominal 230V single-phase, 400V three-phase) |
| `current_a` | float | A | Line current |
| `frequency_hz` | float | Hz | Grid frequency (nominal 50.0 Hz) |
| `power_factor` | float | — | Power factor [0.0, 1.0] |
| `reactive_power` | float | kVAR | Reactive power |

### Battery / DER State

| Field | Type | Unit | Description |
|-------|------|------|-------------|
| `battery_level_kwh` | float | kWh | Current battery state of charge |

### Cryptographic

| Field | Type | Unit | Description |
|-------|------|------|-------------|
| `signature` | bytes (base64) | 64 bytes | Ed25519 signature |
| `public_key` | bytes (base64) | 32 bytes | Signer's public key |

## Derived Fields

| Field | Formula | Description |
|-------|---------|-------------|
| `net_energy` | generated - consumed | Positive = export, negative = import |
| `surplus_energy` | max(net_energy, 0) | Exportable surplus |
| `deficit_energy` | max(-net_energy, 0) | Importable deficit |
| `apparent_power` | √(P² + Q²) | Apparent power (kVA) |

## Precision

Numeric values are rounded for consistency:

| Field | Precision |
|-------|-----------|
| Energy (kWh) | 6 decimal places (0.001 Wh) |
| Voltage (V) | 2 decimal places |
| Current (A) | 3 decimal places |
| Frequency (Hz) | 2 decimal places |
| Power factor | 2 decimal places |
| Reactive power | 3 decimal places |
| Battery (kWh) | 1 decimal place |

## Known Issues

- No power per phase (only aggregate 3-phase value)
- No harmonic distortion data (THD not modeled)
- Battery level is single value — no per-phase SOC
- No temperature measurement (real meters often include temperature sensor)
